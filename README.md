# 붐 크리터스 (Boom Critters)

웜즈·포트리스 스타일의 싱글플레이 턴제 포격 웹게임입니다. 순수 HTML5 Canvas + 바닐라 JavaScript(ES 모듈)이며 빌드 도구가 필요 없습니다.

▶ **플레이**: https://sigco3111.github.io/boom-critters/

## 게임 모드
시작 화면에서 모드를 고릅니다. 진행 상황(해금된 스테이지, 스테이지별 최고 별, 무한 모드 최고 기록)은 브라우저 `localStorage`에 저장됩니다.
- **빠른 대전**: 쉬움·보통·어려움 중 하나를 골라 3 vs 3 단판 승부 (바람 -10~10, 매번 새 지형).
- **스테이지 모드**: 10개 스테이지, 우리 팀 3마리 vs 적 2→4마리(스테이지 1~3은 2마리, 4~6은 3마리, 7~10은 4마리). 스테이지마다 지형이 고정(시드 고정)이고, 스테이지가 오를수록 바람 범위(±4→±13)가 넓어지고 AI 오차가 줄어 정확해집니다. 처음엔 스테이지 1만 열려 있고, 승리하면 다음 스테이지가 해금됩니다(잠긴 스테이지는 회색). 승리 시 별: 생존 3마리 ★★★ / 2마리 ★★☆ / 1마리 ★☆☆ (최고 기록만 저장). 결과 화면에서 **다음 스테이지 / 다시 도전 / 스테이지 선택**을 고를 수 있습니다.
- **무한 모드**: 적을 모두 쓰러뜨리면 다음 웨이브가 새 지형에서 시작됩니다. 웨이브가 오를수록 적이 늘고(2→4마리) 바람이 세지고 AI가 정확해집니다. 웨이브 사이에 생존 유닛은 HP +35, 탄약 보충, 4·7·10…웨이브 직전에는 쓰러진 유닛 1마리가 HP 50으로 복귀합니다. 우리 팀이 전멸하면 끝이며, 점수는 클리어한 웨이브 수(최고 기록 저장).

## 게임 방법
- 파랑 팀(나) 3마리 vs 빨강 팀(AI), HP 100. 상대 팀을 모두 쓰러뜨리면 승리.
- 턴마다 30초. 같은 팀의 유닛이 순서대로 돌아가며 조작합니다. 바람(-10~10)이 매 턴 바뀝니다.
- 폭발은 지형을 원형으로 파냅니다. 물에 빠지면 즉사, 일정 높이 이상 떨어지면 낙하 데미지.
- 무기: **대포탄**(반경 40, 바람 영향 큼, 무한) / **로켓**(반경 58, 바람 영향 작음, 무한) / **수류탄**(같은 각도·파워로 던져 지형에서 튕기고 3초 뒤 폭발, 반경 55, 강한 넉백, 팀당 3발) / **번개**(각도 방향으로 곧게 뻗는 번개, 지형을 관통해 처음 맞은 유닛 하나에게 35 피해 + 약한 넉백, 팀당 2발) / **화염탄**(반경 35 폭발 후 반경 50 화염 지대가 3턴 유지, 팀 턴 시작 시 지대 안의 해당 팀 유닛이 8 피해, 팀당 2발)
- **보급 상자**: 4번째 턴마다(4, 8, 12…) 낙하산을 단 상자가 하늘에서 지형 위로 떨어집니다. 유닛이 닿으면 HP +30(최대 100). 상자는 폭발이 닿으면 파괴됩니다.
- 화면 하단 HUD에 무기 버튼과 남은 탄약(×N, 무한은 ∞)이 표시됩니다. 명중·폭발 거리는 캐릭터 몸통 중심 기준입니다.

## 조작
| 동작 | 키보드 | 마우스/터치 |
|---|---|---|
| 이동 | A / D 또는 ← / → | 화면 ◀ ▶ 버튼 |
| 점프 | W | 점프 버튼 |
| 각도 | ↑ / ↓ | 화면을 드래그 / 각도 버튼 |
| 발사 | Space 꾹 눌러 파워 충전 → 떼면 발사 (번개는 파워와 무관, 각도 방향으로 즉시 발사) | 발사 버튼 꾹 → 떼기 |
| 무기 변경 | 1 대포탄 · 2 로켓 · 3 수류탄 · 4 번개 · 5 화염탄 | 하단 HUD 무기 버튼 / 화면 무기 버튼 |
| 음소거 | M | 우하단 소리 버튼 |

> 참고: 점프와 발사 모두 Space를 쓰면 충돌하므로 점프는 W, 발사 충전은 Space로 나눴습니다.

## 난이도 (AI)
AI는 후보 (각도, 파워) 쌍을 지형·바람과 함께 시뮬레이션해 목표 근처에 떨어지는 값을 고른 뒤, 난이도(스테이지·웨이브에서는 번호에 따라 단계별)에 따른 오차(쉬움 > 보통 > 어려움)를 더해 발사합니다.

AI는 상황에 따라 무기를 고릅니다 (탄약이 남아 있을 때):
1. **번개** — 목표까지 곧은 사선이 있고, 번개가 지형을 관통하더라도 가장 먼저 맞는 유닛이 우리 팀 유닛일 때(아군이 먼저 걸리면 사용하지 않음).
2. **화염탄** — 우리 팀 유닛 둘 이상이 서로 60px 이내에 모여 있을 때.
3. **수류탄** — 목표가 구덩이에 있거나 지형 뒤에 가려져 직사로 맞히기 어려울 때.
4. 그 외에는 **대포탄/로켓**. 빗나가면 목표 쪽으로 걸어가 다시 조준합니다.

또한 HP가 70 미만이고 약 150px 안에 보급 상자가 있으면 상자 쪽으로 걸어가고, 턴 시작 때 화염 지대 안에 서 있으면 밖으로 빠져나옵니다.

## 구조
```
index.html  style.css
js/main.js     진입점, 입력, UI(모드·스테이지 선택·결과 화면), 루프
js/game.js     유닛 물리, 턴 흐름, 투사체, AI, 스테이지/웨이브 설정, 렌더링
js/progress.js 진행 상황 저장 (localStorage)
js/terrain.js  높이맵 생성, 오프스크린 캔버스 지형, destination-out 크레이터
js/audio.js    Web Audio 효과음
assets/        Kenney CC0 Toon Characters 1 캐릭터 포즈(assets/toon)/효과음 (CREDITS.md 참고)
```
로컬 실행: 정적 서버로 폴더를 열면 됩니다 (예: `python3 -m http.server`). ES 모듈 때문에 `file://` 로는 열리지 않습니다.
