# 붐 크리터스 (Boom Critters) — 1단계

웜즈·포트리스 스타일의 싱글플레이 턴제 포격 웹게임입니다. 순수 HTML5 Canvas + 바닐라 JavaScript(ES 모듈)이며 빌드 도구가 필요 없습니다.

▶ **플레이**: https://sigco3111.github.io/boom-critters/

## 게임 방법
- 파랑 팀(나) 3마리 vs 빨강 팀(AI) 3마리, HP 100. 상대 팀을 모두 쓰러뜨리면 승리.
- 턴마다 30초. 같은 팀의 유닛이 순서대로 돌아가며 조작합니다. 바람(-10~10)이 매 턴 바뀝니다.
- 폭발은 지형을 원형으로 파냅니다. 물에 빠지면 즉사, 일정 높이 이상 떨어지면 낙하 데미지.
- 무기: **대포탄**(반경 40, 바람 영향 큼, 무한) / **로켓**(반경 58, 바람 영향 작음, 무한) / **수류탄**(같은 각도·파워로 던져 지형에서 튕기고 3초 뒤 폭발, 반경 55, 강한 넉백, 팀당 3발) / 번개·화염탄(준비 중, soon)
- 화면 하단 HUD에 무기 버튼과 남은 탄약이 표시됩니다. 명중·폭발 거리는 캐릭터 몸통 중심 기준입니다.

## 조작
| 동작 | 키보드 | 마우스/터치 |
|---|---|---|
| 이동 | A / D 또는 ← / → | 화면 ◀ ▶ 버튼 |
| 점프 | W | 점프 버튼 |
| 각도 | ↑ / ↓ | 화면을 드래그 / 각도 버튼 |
| 발사 | Space 꾹 눌러 파워 충전 → 떼면 발사 | 발사 버튼 꾹 → 떼기 |
| 무기 변경 | 1 ~ 5 | 하단 HUD 무기 버튼 / 화면 무기 버튼 |
| 음소거 | M | 우하단 소리 버튼 |

> 참고: 점프와 발사 모두 Space를 쓰면 충돌하므로 점프는 W, 발사 충전은 Space로 나눴습니다.

## 난이도 (AI)
AI는 후보 (각도, 파워) 쌍을 지형·바람과 함께 시뮬레이션해 무작위 플레이어 유닛 근처에 떨어지는 값을 고른 뒤, 난이도에 따른 오차(쉬움 > 보통 > 어려움)를 더해 발사합니다.

## 구조
```
index.html  style.css
js/main.js     진입점, 입력, UI, 루프
js/game.js     유닛 물리, 턴 흐름, 투사체, AI, 렌더링
js/terrain.js  높이맵 생성, 오프스크린 캔버스 지형, destination-out 크레이터
js/audio.js    Web Audio 효과음
assets/        Kenney CC0 Toon Characters 1 캐릭터 포즈(assets/toon)/효과음 (CREDITS.md 참고)
```
로컬 실행: 정적 서버로 폴더를 열면 됩니다 (예: `python3 -m http.server`). ES 모듈 때문에 `file://` 로는 열리지 않습니다.
